# Shelfday

A daily prep, perishable-stock and closing workbench for independent cafés and takeaway kitchens.

Work in progress. This initial milestone records [research](docs/research.md), [product design](docs/superpowers/specs/2026-11-06-shelfday-design.md) and the [implementation plan](docs/superpowers/plans/2026-11-06-shelfday.md). Later milestones add the tested engine, persistent API, interface, and verified delivery.

No claims of savings or food-safety assurance. Sample data will be opt-in. Stock dates and quantities require accurate operator entry.
